# DAMS Micro

DAMS Micro is a microfinance accounting and lending system built with Laravel, React, Inertia, and Tailwind CSS. It combines a double-entry general ledger with a loan portfolio module.

## Requirements

- PHP 8.3+
- Composer 2
- Node.js 20+
- pnpm (recommended, the repository includes a `pnpm-lock.yaml`)
- SQLite (default) or PostgreSQL 14+

## Quick start

```bash
git clone <repository-url> dams-micro
cd dams-micro

# Install PHP dependencies
composer install

# Create the environment file and application key
cp .env.example .env
php artisan key:generate

# Create the SQLite database (skip if you use PostgreSQL)
touch database/database.sqlite

# Install JavaScript dependencies
pnpm install

# Run migrations and seed demo data
php artisan migrate:fresh --seed

# Start the application
php artisan dev
```

The app is available at [http://localhost:8000](http://localhost:8000).

`php artisan dev` starts the PHP server, queue listener, log viewer, and Vite dev server together. If you prefer npm, run `npm install`, then use `php artisan serve` and `npm run dev` in separate terminals, since `php artisan dev` automatically uses pnpm when it finds a pnpm lockfile.

## Environment variables

Copy `.env.example` to `.env`, then set the values for your machine. The important ones are:

| Variable | Default | Description |
| --- | --- | --- |
| `APP_NAME` | `Laravel` | Application name. Set this to `DAMS Micro`. |
| `APP_ENV` | `local` | Environment name. Use `local` for development. |
| `APP_KEY` | empty | Generated by `php artisan key:generate`. Required. |
| `APP_DEBUG` | `true` | Show detailed errors locally. Set to `false` in production. |
| `APP_URL` | `http://localhost:8000` | Base URL of the application. |
| `DB_CONNECTION` | `sqlite` | Database driver. Use `sqlite` or `pgsql`. |
| `DB_DATABASE` | `database/database.sqlite` | SQLite file path, or the PostgreSQL database name. |
| `DB_HOST` | `127.0.0.1` | PostgreSQL host. Only used with `pgsql`. |
| `DB_PORT` | `5432` | PostgreSQL port. Only used with `pgsql`. |
| `DB_USERNAME` | empty | PostgreSQL username. Only used with `pgsql`. |
| `DB_PASSWORD` | empty | PostgreSQL password. Only used with `pgsql`. |
| `SESSION_DRIVER` | `database` | Session storage. The required table is created by migrations. |
| `CACHE_STORE` | `database` | Cache storage. The required table is created by migrations. |
| `QUEUE_CONNECTION` | `database` | Queue driver used by the queue listener. |
| `MAIL_MAILER` | `log` | Mail driver. `log` writes emails to the log instead of sending them. |
| `VITE_APP_NAME` | `${APP_NAME}` | Application name exposed to the frontend. |

### Using PostgreSQL instead of SQLite

Create a database named `dammy_micro`, then update `.env`:

```dotenv
DB_CONNECTION=pgsql
DB_HOST=127.0.0.1
DB_PORT=5432
DB_DATABASE=dammy_micro
DB_USERNAME=postgres
DB_PASSWORD=your-password
```

## Seeded data

`php artisan migrate:fresh --seed` drops all tables, re-runs every migration, and seeds demo data, including a test user:

- Email: `test@example.com`
- Password: `password`

It also seeds a company, system settings, ledgers, chart of accounts, loan products, and sample loan records. Only run `migrate:fresh` on a local or development database, because it deletes existing data.

## Useful commands

```bash
# Reset the database and seed it again
php artisan migrate:fresh --seed

# Run the test suite
php artisan test

# Check and fix PHP formatting
composer lint

# Build frontend assets for production
pnpm run build

# Review generated routes
php artisan route:list
```

## Troubleshooting

- **`Unable to locate file in Vite manifest`**: run `pnpm run build`, or make sure the Vite dev server is running through `php artisan dev`.
- **`Database file at path ... does not exist`**: create it with `touch database/database.sqlite`, or set a valid PostgreSQL connection in `.env`.
- **`No application encryption key`**: run `php artisan key:generate`.
- **Port 8000 already in use**: stop the other process, or run `php artisan serve --port=8001` and update `APP_URL` to match.
- **`pnpm: command not found`**: install pnpm with `npm install -g pnpm`, or use the npm workflow described above.
